## 一、研究背景与意义

### 1.1 选题背景

道路裂纹是道路损坏的早期表现形式，及时检测和修复对于保障交通安全、延长道路使用寿命具有重要意义。传统的人工巡检方式存在以下问题：

1. **效率低下**：人工巡检覆盖范围有限，难以满足大规模道路网络的检测需求
2. **成本高昂**：需要投入大量人力物力，且作业周期长
3. **主观性强**：检测结果依赖于巡检人员的经验和判断，缺乏统一标准
4. **实时性差**：无法实现对道路状态的实时监测和预警

### 1.2 研究意义

本系统利用深度学习技术实现道路裂纹的自动化检测，结合云端协同架构，具有以下创新意义：

- **技术创新**：采用ConvNeXt+UPerNet混合架构，结合边界感知和深度监督技术，实现高精度裂纹检测
- **工程实践**：构建完整的云端协同检测系统，具备数据管理、模型推理、结果可视化、报告生成等功能
- **应用价值**：为道路养护部门提供智能化、精准化的决策支持工具

## 四、已完成的研究内容

### 4.1 深度学习模型模块（100%完成）

#### 4.1.1 模型架构设计

采用 **ConvNeXt + UPerNet** 混合架构：

- **编码器（ConvNeXt）**
  - 支持 Tiny/Small/Base/Large 多种规格
  - ImageNet-22K 预训练权重
  - 4层特征金字塔输出（1/4, 1/8, 1/16, 1/32）

- **解码器（UPerNet）**
  - PPM金字塔池化模块（多尺度上下文）
  - FPN特征金字塔网络（多尺度融合）
  - CBAM注意力机制（通道+空间注意力）
  - Strip Pooling条形池化（针对细长裂纹优化）

- **辅助模块**
  - 边界检测分支（Sobel算子 + 边界增强）
  - 深度监督（3个辅助分类头）

**代码位置**：`python-inference/models/convnext_upernet.py`

#### 4.1.2 损失函数设计

组合多种损失函数优化训练：

```
Total Loss = 1.0 × BCE Loss       (基础分类)
           + 1.0 × Dice Loss      (区域重叠)
           + 0.5 × Focal Loss     (难样本挖掘)
           + 0.2 × Boundary Loss  (边界精细化)
           + 0.3 × Edge Loss      (边界分支监督)
           + 0.4 × Auxiliary Loss (深度监督)
```

**代码位置**：`python-inference/training/losses.py`

#### 4.1.3 训练策略

- **优化器**：AdamW (weight_decay=0.01)
- **学习率**：Cosine Annealing with Warmup
- **正则化**：Weight Decay, Dropout, Label Smoothing
- **训练技巧**：
  - 混合精度训练（AMP）- 节省50%显存
  - 梯度累积 - 模拟大batch size
  - 指数移动平均（EMA）- 稳定模型

**代码位置**：`python-inference/training/trainer.py`

## 六、技术创新点

### 6.1 模型层面创新

1. **条形池化模块（Strip Pooling）**
   - 专门针对细长裂纹特征设计
   - 在水平和垂直方向分别进行条形池化
   - 有效捕获长距离依赖关系

2. **边界感知分支**
   - 基于Sobel算子提取边界特征
   - 独立边界监督损失
   - 提升裂纹边界精度

3. **多损失函数组合**
   - Dice Loss处理类别不平衡
   - Focal Loss挖掘难样本
   - Boundary Loss精细化边界

### 6.2 工程层面创新

1. **混合微服务架构**
   - Java处理业务逻辑，Python处理AI推理
   - 充分发挥两种技术栈的优势

2. **高效数据管道**
   - LMDB缓存加速I/O（10x提速）

3. **推理优化策略**
